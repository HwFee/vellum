# 速查：症状 → 根因 → 修法

出问题、或出图前自查时按症状找。`契约 N` 指 `widget-contracts.md`；`mdlog-live` 指 `references/mdlog-live.md`。

| 症状 | 根因 | 修法 |
|---|---|---|
| 大段文字讲解结构/流程/对比 | 文字抢了图的活 | 成图承载，文字只做引子与串讲（`SKILL.md` 步骤 1） |
| 用 `text` 围栏排了占比条/进度条（`[==== 40% ====]`） | 把「数据分布/占比」当成了文字清单 | 分布、占比、权重、排名也是图：水平条形 SVG（`SKILL.md` 步骤 1） |
| 出现字符画灰块 | 用代码块画了图 | 改画 `vellum-widget` 静态 SVG（`SKILL.md` 步骤 1） |
| 日志里出现过程碎碎念 | 把探索/校验写成了正文 | 过程只进思考与工具调用（`mdlog-live`） |
| 正文引用块被点上朱红章 | blockquote 是用户回合专用 | 加粗段首或普通段落（`mdlog-live`） |
| 在 Vellum 外（GitHub/VS Code）渲染出字面 `**` / `~~` | 定界符跨「汉字+括号」交界 | 粗体停在汉字上、括号注释放粗外（可移植性：粗体两侧都贴汉字/字母） |
| `SecurityError: Access is denied for this document` | 碰了 `localStorage` / `sessionStorage` | 状态改内存变量（契约 3） |
| 高度坍缩为 0 / 不随内容伸缩 | 缺通信 IIFE 或消息类型写错 | 照抄契约 5 的 IIFE |
| 控制台报 CSP 拒绝 | 引用了 CDN / 外链 | 全部手写内联（契约 2） |
| 交互块渲染成普通代码块 | 围栏标识写错（`html`、`widget`…） | 标识逐字 `vellum-widget`（契约 1） |
| 围栏被内部反引号提前截断 | 正文含三反引号 | 外层围栏用四个以上反引号（契约 1） |
| 图内文字与框重叠/溢出 | 跳过出图流程直接输出 | 走 `SKILL.md` 步骤 3–4：自查 + `check-widgets.mjs` 修到 exit 0 |
| 小方块的标注骑压边框 | 小图元硬塞多行文字 | 宽 < 56px 图元标签一律放形外（契约 6 第 4 条） |
| 图内文字太小看不清 | 字号低于下限 | 正文标注 ≥ 15px，图注 ≥ 12.5px（契约 4） |
| 排版与 Vellum 主界面割裂 | 用了无衬线体 / 字重超标 | kami token + 衬线栈，字重 ≤ 500（契约 4） |
| 出现 emoji 图标 | 违反纸墨质感 | 换 SVG 发丝线或汉字标签（契约 4） |
| 在 mdlog 之外的文档里，widget 只显示「点击加载」 | 宿主授权门禁，非 bug | 点一次即可（同一份内容记住）；交付时告知用户（契约 7） |
| 内联 `<svg>` / `<button>` / `style=` 在正文里消失 | rehype-sanitize 白名单剥掉 | 改放 `vellum-widget` 围栏（`SKILL.md` 步骤 1） |
| 静态图滚轮在图上被吃掉 / 被判成交互块 | `<script>` 里除通信 IIFE 外还有内容（含注释） | 注释放 `<script>` 之外（契约 7） |
| 切到别处再回来，演示回到初始态 | 被 LRU 休眠，内存状态丢失 | 设计成默认态可重入，别存一次性进度（契约 7） |
| `alert` / `confirm` 没反应 | 沙箱无 `allow-modals` | 用页内文字提示代替 |
