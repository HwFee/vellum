# mdlog 实时日志专属规则

仅当工具表里有 `vellum_figure`（记录连接已建立，扩展只在记录期间激活它，断开即摘除）时读。该分支每条回复都适用，不等用户开口。

## 过程静默

正文会被**逐字**写入日志并渲染给用户看。

- 作图、校验、探索、重试的过程只进内部思考与工具调用。
- 最终回复只写结果：图示 + 精练串讲。
- 日志文件由扩展维护：标题、回合结构、指纹与锚点都不用写；图示走 `vellum_figure`，围栏源码留在正文之外。

## 引用块归用户回合

宿主给 `>` 开头的 blockquote 点朱红章、加顶线，把它当成用户发言。需要引用、注记、强调时，用加粗段首（如 `**注**：…`）、普通段落或列表。用户回合的引用块由扩展自动写入。

## 图的投递

1. 按主流程完成草稿并过 `check-widgets`（exit 0）。
2. `vellum_figure(path=<草稿路径>)` 投递，源码不进对话。
3. 它回一枚 `<!-- mdlog-fig:ID -->`：**整枚照抄、单独成行**，放在图该出现的位置（图前引子之后、图注之前）。漏放时图会在回合末尾补上，位置就不由你定了。
4. 非记录态才把 HTML 写进正文围栏。

## 图片引用

用 `imagen2` 等工具生成图片后，正文写标准 Markdown 引用，路径带引号：

`![傅里叶合成示意图]("generated-images/fourier-series.png")`

扩展会把回合内图片复制到日志同级 `mdlog-assets/` 并改写路径；重命名、搬移、Base64 编码都由它代劳。
