样式辨识度占地与既有语汇的关系未落墨 / 已落墨 区分方式
01 方形角标高极小（骑线）同大纲 2px 端头文字 + 靛青→纸灰
02 实色标签高小（块内）同提示条 --tag-bg文字 + 底色调暗
03 印章高中（压出块外）同「墨迹未干」印章文字 + 边框变灰
04 朱点低（需 hover）极小新语汇点的实/虚
05 竖排签中中（占左留白）书卷题签文字 + 墨色深浅
06 直角线低极小发丝线线的实/虚
07 圆点状态低极小同「未保存」点实心 / 空心
08 双线角标中小（骑线）发丝线 + 墨色字文字 + 墨色→发丝线
