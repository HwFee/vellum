导出为 PDF · 纸张舞台（定稿）

2026-09-21 · 选定方案三 · 页面规格对齐上游 kami（WeasyPrint 模板）

上游 kami 的 PDF 由 HTML 模板经 WeasyPrint 生成，纸张、边距、底色都是模板里的常量，从不交给用户挑。本设计照此办理：不设纸张与边距选项，整扇窗只留纸面预览、文件名与一枚导出章。纸面直接引用 src/styles/kami.css 与 public/fonts/ 的仓耳今楷，所见即纸上所得。

上游依据

tw93/kami · references/production.md Part 1「HTML → PDF (WeasyPrint)」

@page {
  size: A4;              /* 纸张是模板常量 */
  margin: 20mm 22mm;     /* 边距也是模板常量 */
  background: #f5f4ed;   /* 宣纸底色漫过边距，不留白边 */
}

@page {
  @top-right    { content: counter(page);          /* 页码：衬线 9pt 石灰 */ }
  @bottom-center{ content: "{{DOC_NAME}} · {{AUTHOR}}"; }
}
@page:first { @top-right { content: "" } @bottom-center { content: "" } }  /* 首页干净 */

页码与页脚自第二页起出现，首页不落款；另有一种「白纸打印」变体（@page 背景换白、ivory 浮层改由宣纸承接），上游标注为家用打印机省墨的可选配方，默认仍是宣纸。

定位　预览即主角：纸面铺满窗口，唯一的控件是底部一条浮动工具条——固定的页面规格以一行小字陈列（A4 · 20/22mm · 宣纸），不是选项。

取舍　文件名收进工具条（点按即编辑）；若日后要「白纸打印」变体，可在规格小字旁加一枚两档纸色开关——上游认可的唯一可选项。

定稿细节

  • 入口　Ctrl+P 与顶栏按钮打开本视图（替换正文区，同设置页），不再调 window.print() 的系统对话框；Esc 或「‹ 返回阅读」退出。
  • 页面规格　A4 纵向，边距 20mm / 22mm，宣纸底色 #f5f4ed 漫至纸边——全部固定，对齐上游模板常量。
  • 页眉页脚　页码自第 2 页起居右上（衬线 9pt 石灰）；页脚居中「文档名 · 素笺」；首页两者皆空。
  • 版式　纸面与阅读页渲染同一棵 Markdown 树，字号 / 栏宽 / 行高跟随阅读设置；分页保护沿用现有 @media print 的规则（代码块、表格、引用不跨页，标题不落页脚）。
  • 文件名　默认取文档题（如 小窗幽记-卷一.pdf），工具条内就地改名；导出时经系统保存对话框选落盘位置。
  • 实现定稿（2026-09-21 真机验证）　后端对主窗口 WebView2 直调 CDP Page.printToPDF（preferCSSPageSize:true，边距 20/22mm 按英寸传）；页码页脚用 CSS @page 边盒（Chromium 131+ 认，真机实测渲染正确，由导出视图运行时注入，文档题是运行时值）；纸面底色必须刷 @page { background: var(--parchment) }——body 背景在分页时不传播满页边区，会漏白（PPM 逐像素取证）。预览分页按行摹 Chromium：段落按行盒拆分、孤行寡行 = 2、标题随块换页（src/lib/exportPagination.ts）。
