实现要点

  • 描边入场　每个图形加 pathLength="1" 归一化，dasharray:1 → dashoffset 1→0 就是 0–100% 的描绘进度，免逐条量长度；--i 控制次第，实色点（stroke="none"）改淡入。
  • 变换基准　svg 叶子形一律 transform-box: fill-box，位移 / 缩放 / 旋转各归各的包围盒，不串位。
  • 换章　两枚 svg 叠放（笔↔书、复制→对勾/叹号）：旧章 opacity+rotate+scale 退、新章描边进；真身里新章挂载时挂上 .draw 即可。
  • 克制　位移 ≤ 2.5px、时长 ≤ 0.35s（换章与出纸动画除外），prefers-reduced-motion 一刀切——本页底部已内置同款媒体查询。
  • 落地路径　看中的逐枚搬回对应组件 svg（包一层 <g> 或加 class），样式进 kami.css 邻近段；此页全部动效为纯 CSS，无运行时依赖。
本页直接引用 src/styles/kami.css 与 public/fonts/，按钮壳（.open-button / .window-control / .outline-search__nav / .code-block__copy / .jump-bottom）全是真身样式，只有图标内部的动效是原型。双击本文件即可在浏览器中查看。
