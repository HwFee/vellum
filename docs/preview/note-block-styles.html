③　[[wikilink]]

现在库内链接是靛青 + 点状下划线（外链是实线下划线 + ↗），失效目标是灰字 + 虚线。三个候选是「怎么让人一眼看出这是库内笔记」。

候选 1

点状下划线（现状）

靠下划线样式与外链区分：点线 = 库内，实线 = 外链。除颜色外几乎不占位置。

点线与实线的差别很细，快速扫读时容易忽略；在满屏正文里链接密度高时略吵。

std::move 只是把 x 转成右值（见 wiki/concepts/cpp-std-move），真正干活的重载由 x 的静态类型决定。

官方定义见 cppreference；本文引用的 wiki/concepts/cpp-move-construction 在库里找不到。

候选 2

括注式小标签

库内链接带一层淡蓝底 + 起首小方点，和外链彻底分开——扫一眼就知道哪些词能点进另一篇笔记。

带底色会抬高行内重量，正文里链接多时像撒了一层色块；与 tags 的 chips 容易混。

只靠色与字重，悬停才出线

候选 1

色块（现状）
