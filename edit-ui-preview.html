编辑体验

阅读态就是现在这样：字落在纸上，没有任何编辑器的味道。

- 进入编辑视图后，鼠标点哪一块，哪一块就地变成源码 - 顶栏标题旁一个墨点：有草稿未落盘 - 点走 / Esc 即提交落盘，墨点消失

下面是两类只读块：

<div class="payload">块级 HTML：只读，点击只出一次极轻的提示</div>
交互块 · 只读
widget 沙箱（点击仍可交互）

语汇 最安静

  • 编辑视图：顶栏按钮变「书」，正文所有可编辑块 hover 时浮现左轨 2px 靛青细线
  • 正在编辑：该块左轨实心 + 源码等宽显示（与大纲激活项同一语汇：2px 端头方块）
  • 未保存：顶栏标题右侧一个 6px 靛青墨点；提交后墨点化为发丝灰
  • 只读块：hover 左轨为发丝虚线，不出现任何文字标签

取舍

  • 优点：最不打扰，阅读→编辑的切换只有一处变色
  • 缺点：「未保存」在视线之外（你正在打字的位置离顶栏很远），且只读块靠 hover 才可知
  • 实现成本：最低（一个类 + 一个圆点）

编辑体验

阅读态就是现在这样：字落在纸上，没有任何编辑器的味道。

段落未保存
- 编辑中的块上方浮一条极窄工具条 - 右侧三个文字按钮：撤销 / 保存 / 完成 - 「未保存」二字随草稿状态变化

下面是两类只读块：

HTML · 只读
<div class="payload">块级 HTML：只读，标签常驻在块左上角</div>
交互块 · 只读
widget 沙箱（点击仍可交互）

语汇 语义最明确

  • 正在编辑的块：上方一条 18px 工具条（发丝线上边 + 纸底），左「段落」，右「未保存 / 撤销 / 保存 / 完成 ⏎」
  • 未保存二字就在鼠标附近，改完立刻可见；保存后变为「已保存」并在 1.2s 内淡出
  • 只读块：左上角常驻极小实色标签「HTML · 只读」「交互块 · 只读」——不靠 hover 猜

取舍

  • 优点：把「这块在编辑 / 还没保存 / 能撤销」全部说清，且按钮给了鼠标用户退路
  • 缺点：块上方多一行 chrome，与「最安静的阅读器」气质冲突最大；触碰「不加工具栏」的原定边界
  • 实现成本：最高（新组件 + 焦点/快捷键协调）

编辑体验

阅读态就是现在这样：字落在纸上，没有任何编辑器的味道。

- 编辑中的块四周一圈 1px 靛青发丝框，左上角方形角标写块类型 - 草稿有改动时右下角一枚小印：「未落墨」 - 提交后小印换成「已落墨」并淡出

下面是两类只读块：

<div class="payload">块级 HTML：hover 时整块轻微下沉 1px，表示「动不了」</div>
交互块
widget 沙箱（点击仍可交互）
未落墨

语汇 最像「纸」

  • 编辑中的块：四周 1px 靛青发丝框 + 左上角方形角标「段落」（方形端头与大纲指示条同语汇）
  • 未保存：右下角一枚微斜 −1.5° 的小印「未落墨」→ 提交后变「已落墨」并淡出（延续既有「墨迹未干」印章的隐喻）
  • 只读块：hover 下沉 1px（触感「不能动」），不给文字标签

取舍

  • 优点：状态就在被编辑的块上，隐喻与项目既有印章一致；不需要新增整条 chrome
  • 缺点：一个块四周加框，在密集文档里会比变体 1 更「重」；小印是浮层，长块滚出视野时看不到
  • 实现成本：低-中（框 + 角标 + 一枚浮层印）

统一语义（四版共用）：阅读视图 = 纸页无 chrome；编辑视图 = 顶栏图标由「笔」变「书」；块级只读 = HTML / 交互块永远没有编辑入口；未保存 = 草稿已改但尚未提交落盘（点走 / Esc / Ctrl+S 即落盘）。
