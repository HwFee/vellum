# Warp Shuffle 四兄弟：一张幻灯片读懂

**先做这一步**：把下面四个函数记成一句话——「线程之间不经过内存，直接读邻居寄存器」。读完全文约 6 分钟。

这是 B 站《【CUDA】硬件与工具探索合集》第 30 页（共 35 页，视频 06:43 处）的讲解。上一页（第 29 页）先讲了 `shuffle`：在一个 warp（32 个线程）内部交换寄存器数据。这一页把四个变体并排画出来，用「读谁的值」区分。

## 第 1 步：看懂图上的符号（1 分钟）

- 上排方格 **x**：每个线程手里原有的值。一个 warp 共 32 格，图里一行就是 32 个 lane。
- 下排方格 **y**：调用函数后每个线程得到的值。
- 连线：从哪个 lane 的 x 取值，送到哪个 lane 的 y。
- 红框：幻灯片里框出的是 lane 0，用来看它读到了谁。
- `mask = 0xffffffff`：32 个线程全部参与。少一个线程就是未定义行为。
- `width = warpSize`：把 warp 切成若干段，每段互不干扰；默认不切（整段 32）。

**注**：下面三张图为了看得清，用 8 个 lane 代替 32 个，原理完全一样。

## 第 2 步：广播 `__shfl_sync`（1 分钟）

签名：`T __shfl_sync(unsigned mask, T var, int srcLane, int width=warpSize)`

幻灯片的两个例子：`srcLane=2`、`width=32` 时，32 个线程全部读 2 号线程的值；`width=16` 时 warp 切成两段，每段都读**段内**的 2 号线程。

## 第 3 步：平移 `__shfl_up_sync` 与 `__shfl_down_sync`（2 分钟）

签名：

- `T __shfl_up_sync(unsigned mask, T var, unsigned delta, int width=warpSize)`
- `T __shfl_down_sync(unsigned mask, T var, unsigned delta, int width=warpSize)`

规则：`up` 读编号更小的邻居（`y[i] = x[i - delta]`），`down` 读编号更大的邻居（`y[i] = x[i + delta]`）。越界的线程**保持自己原来的值**。幻灯片里 up 用了 `delta=2、16`，down 用了 `delta=3、8`，delta 越大，斜线越陡。

| `__shfl_down_sync` | `i + delta` | 保留自己 | 归约 |
| `__shfl_xor_sync` | `i ^ laneMask` | 无 | 蝶形归约 |

## 已经学会的东西

- 看到 `x → y` 连线图，能说出每条线是从哪读到哪。
- 能区分四个函数：广播、左读、右读、异或配对。
- 知道 `mask` 要写全员，`width` 用来分段。
